# data-analysis-dashboard-excel
Interactive Sales Performance Dashboard built in Excel using Pivot Tables and Slicers to identify sale trends.
Project Overview: Laska Store Sales Analysis
This is a personal project focused on end-to-end data analytics using Microsoft Excel. I analyzed a dataset from Laska Store (Vrinda Store) containing 31,000+ rows of e-commerce data to identify key growth drivers for 2023.

The Core Challenge
The store needed to understand its customer base to improve marketing efficiency. I processed the raw sales data to answer: Who are the top customers, and where should we spend our ad budget?

Key Data Insights
Primary Target: Women aged 30-49 are the most profitable segment, contributing over 60% of total revenue.

Top States: Maharashtra, Karnataka, and Uttar Pradesh lead in sales volume.

Channel Strategy: 80% of sales occur via Amazon, Flipkart, and Myntra, suggesting a focus on these platforms for maximum ROI.

Tools & Techniques
Data Cleaning: Used Find & Replace and filters to standardize messy gender and size data.

Data Engineering: Created custom Age Buckets (Adult, Teenager, Senior) using nested logic and extracted monthly trends using the TEXT function.

Visualization: Developed an Interactive Dashboard featuring Pivot Tables, Slicers, and dynamic charts for real-time data exploration.
